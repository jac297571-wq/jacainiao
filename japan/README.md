# 日本ロト研究（ロト6 / ロト7 / ミニロト）

数据：`scripts/fetch_loto.py` 抓自 loto6.jp / loto7.jp / miniloto.jp 的同构数据接口。字段包括本数字、出球顺序（ロト6/7）、セット球（A–J）、各等奖金与注数、キャリーオーバー、销售额。ロト6 共 2144 回，与 thekyo.jp 的 CSV 逐回核对一致。

| 研究 | 报告 | 结论 |
|---|---|---|
| 号码均匀性 / 变点 / セット球指纹 / 套号预测 | [report_loto6.md](report_loto6.md)、[report_loto7.md](report_loto7.md)、[report_miniloto.md](report_miniloto.md) | 号码均匀，20 多年没有变点。セット球**没有**号码指纹，但**用哪套可以预测**："最久没用的那套"命中率 45–51%（随机 10%） |
| ロト7 分套模型置换检验 | [report_loto7_perm.md](report_loto7_perm.md) | 置换 p=0.030；考虑多重比较后约 0.06–0.09，属边缘结果。即使为真，效应也不到头奖概率的 1% |
| キャリーオーバー期望回报 | [report_carryover.md](report_carryover.md) | 任何滚存水平下回报率都远低于 1（最高约 0.70）。头奖单注上限让滚存只能分多期慢慢派出 |
| 颜色效应（7 色按套轮换） | [report_color.md](report_color.md) | 三种彩票、新旧两批球都**没有**颜色效应，号码组对照同样为阴性 |

| ロト6 深入：リハーサル（A セット 907 回）、同夜状态、出球物理、会场、换球 | [report_loto6_deep.md](report_loto6_deep.md) | A セット无指纹；リハーサル与正式开奖无关联（同一套球同一晚也一样）；没有顺序或相邻残留；换球前后无变化 |
| 第二轮深挖：追热球历史回测、跨彩种一致性、印刷墨量、出球早晚、星期几 | [report_deep2.md](report_deep2.md) | 雷达在大乐透真实偏差期使头奖概率 ×1.3–1.56；日本历史上追热球 ×1.0–1.3，从不吃亏（合并 z=+1.8，ロト7 最强）。号码级固有物理偏差全部阴性，偏差只可能是阶段性的 |
| ロト6 买家偏好与冷门号码期望回报 | [report_popularity.md](report_popularity.md) | 偏好可预测（R²≈0.56；偏爱 ≤31 生日号、≤12 月份号）。冷门号码使期望回报提高约 17%（0.39→0.46，滚存 10 亿时 0.71→0.80），但最高也只有约 0.82 |

**总结**：日本ロト在开奖机制（离心式"夢ロト君"）、球的工艺（颜色按套轮换）和奖金规则（头奖设上限）上都设计得很严密。我们找到的唯一非随机结构是"套号按轮换规则选取"，但各套球之间没有可利用的差异，所以这一点对选号没有价值。

**唯一实用的建议**：如果买ロト6，选冷门号码（避开 ≤31、尤其是 ≤12，多用 32–43，避开 23/12/08/24/03/11 等热门号）。中奖概率不变，但中奖时分得更多，期望回报约提高 17%。它仍然是负期望。
