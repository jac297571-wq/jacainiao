# 大乐透研究：能不能做最幸运的那一个？

数据：2007-05 ~ 2026-10 全部 **2932 期**开奖（`data/dlt_history.csv`，来源 500.com）。
复现：`python3 scripts/fetch.py && python3 scripts/analyze.py`，完整输出见 `analysis.txt`。
深度检验：`pip install numpy scipy && python3 scripts/deep.py`，报告见 [`report_deep.md`](report_deep.md)。

## 结论（一句话）

**现在的大乐透开奖是真随机的，没有任何选号方法能提高中奖概率；唯一能做的是：中了的时候少跟人分钱。**

## 关键发现

| # | 问题 | 结果 |
|---|------|------|
| 1 | 头奖有多难？ | 1 / 21,425,712。每周 3 期各买 1 注，平均约 **13.7 万年**中一次 |
| 2 | 号码均匀吗？ | **2007–2016 不均匀**：29–35 号明显偏多（χ²=166 / 61，远超临界值 48.6），疑似早期摇奖球/设备偏差。**2017 年后完全均匀**（χ²≈26，正好是随机水平） |
| 3 | 冷热号有用吗？ | 全时段回测"追热号"前区命中 0.775（期望 0.714，+4σ）——但这全是 2016 年前的设备偏差带来的。**2017 年后热号 0.727、冷号 0.723、随机 0.734，没有区别** |
| 4 | 选号影响奖金吗？ | 会。有 ≥2 对连号的开奖，一等奖注数中位数高约 30%（1.72 vs 1.33 注/亿元销量），即更多人买、奖金被分薄。历史最多一期 106 注同中（16150） |
| 5 | 奖金实际多少？ | 近 3 年一等奖单注中位数 1000 万（封顶），最低一期仅 239 万（26113 期：02 04 06 10 11，37 注平分） |

## 如果一定要买

1. **随机机选**，别迷信冷热号、走势图、"缩水"软件——2017 年后它们都等于随机。
2. **避开热门组合**：连号、等差数列、全在 1–31（生日）的号、上期号码。不提高中奖率，但中了少被分。
3. 期望回报约每 2 元回 1 元（法定返奖率约 50%），**当娱乐消费，不当投资**。

## 有意思的副产品

2007–2016 年的偏差是真实且可被利用的（前区追热号显著优于随机），说明早期设备确实有问题，后来被修正了。这也是全部研究里唯一"不随机"的信号。

## 深度检验（`scripts/deep.py`）

共 171 项检验，覆盖 5 个时段（全部、2016 年前、2017 年后、2017–21、2022–26）：

- **频率与组合**：前区和后区号码频率、前区两两同出（595 对）、后区组合、前区和后区是否相关
- **切片**：和值、跨度、奇偶、大小、质数、连号、三区比、尾数、AC 值、按大小排序后每个位置的号码分布，都和精确理论分布对比（全部 32 万种组合逐一列举）
- **时序**：与 1–10 期前的重号数、遗漏分布与几何分布对比、每个号码的自相关、和值序列的 Ljung-Box 检验
- **分段**：周一、周三、周六分开检验，再用 300 期滚动窗口定位偏差消失的时间点
- **反向策略**：杀上期号、杀热号、杀冷号、杀遗漏最久的号、4 种常见杀号公式，以及对应的选号策略

以下 p 值和 q 值都是单次检验的。171 项检验里纯随机也会冒出约 9 个 p<0.05，所以真正算数的是 q（BH-FDR 多重检验校正后）<0.05，而且要在两个不重叠的时段里都出现。

| 发现 | 结论 |
|---|---|
| 2014 年前后有一次明显的设备或流程切换 | 滚动 χ² 显示，13xxx 期之后 29–35 号偏多的现象消失（出现率从理论值的 1.4 倍回到约 1.0 倍） |
| 2016 年前偏大号 | 偏差在和值、各位置、三区比、两两同出上都显著（q 低至 1e-23），形态统一：整体往大号偏 |
| 杀号公式 | 全部无效，成功率和理论值的差在 ±1σ 以内 |
| 杀热号、杀冷号、追遗漏 | 2017 年后都和随机一样 |
| 时序和记忆 | 2017 年后没有任何期与期之间的相关性（重号、遗漏、自相关、和值序列都正常） |
| **2022 年起偏小号（唯一的新信号）** | 每期开出 1–12 号的个数，2022–24 年为 1.832（p=0.006），2025–26 年为 1.871（p=0.005），理论值 1.714。两段时间不重叠，方向一致 |

### 小号偏移：值得关注，但不值得押注

- 1–12 号的出现率比理论高约 7.7%。如果偏差是真的，一注前区 5 个全在 1–12 的号码，头奖概率大约变为 1.4 倍。这仍然是约 1/1500 万，期望回报仍然远低于成本。
- 小号正是大家爱买的生日号。26113 期开出 02 04 06 10 11，37 注平分头奖，每注只剩 239 万，中了也会被分薄。
- 这个假设是看过全部数据后才找到的，严格来说不算事先登记。请继续用 F 节跟踪：之后几十期如果均值回落到 1.71 附近，就是噪声。

**最终结论不变：2017 年后的开奖在统计上是随机的，没有可以盈利的规律。**

## cifulucky：每期 5 注选号器

```bash
python3 cifulucky.py --update   # 抓最新开奖 → 生成下一期 5 注，存到 picks/
python3 cifulucky.py check      # 开奖后对奖，累计统计命中分布
```

| 机制 | 作用 |
|---|---|
| 小号信号 | 每次用最近 500 期重新检验 1–12 号是否偏多。z>2 才加权，并向均匀收缩 50%；信号消失则自动变成纯随机 |
| 防平分过滤（可选，`--anti-split`） | 排除三连号、≥2 组连号、4 项等差、全奇或全偶、与上期重 ≥3 个号、后区连号。不影响中奖率，只影响中了以后被平分的程度，默认关闭 |
| 5 注分散 | 任意两注前区最多重 2 个号，后区互不相同 |
| 真随机 | 用系统熵源（`secrets`），不设种子 |

先说清楚：小号信号即使是真的，也只是把每注的中奖概率乘上一个略大于 1 的倍数，期望回报仍然是负的。这个工具的目的是在纯随机的基础上，捡起数据里能找到的每一点边际优势。

## 新切入点（`scripts/novel.py` → [`report_novel.md`](report_novel.md)）

数据新增 `data/dlt_order.csv`：2011 年起每期的**出球顺序**（来源 17500.cn）。

| 切入点 | 结果 |
|---|---|
| **混合不充分**：摇奖球按号码顺序码放，相邻号码是否更常一起出 | 所有时段方向一致、都偏多（z 约 +1.5~+2）。全部历史中“同期有连号”占 49.8%，理论值 47.7%，z=+2.28。这和“避开连号”的民间说法正好相反 |
| **出球顺序**：第 k 个出的球是否有偏 | 2022 年后的小号偏移主要集中在第 3 个出的球（1–12 号占比 0.405，z=+3.5），说明这更可能是物理原因，而不是统计上的巧合 |
| **预测模型样本外打分**（逐期滚动、对数损失） | 只有“小号偏移”模型跑赢随机（+4.6 比特，z=+2.0）。所有按单个号码统计冷热的模型都输给随机（z 低至 −5），因为它们在拟合噪声 |

**对组合的结论**：只能利用粗粒度的结构信号（号码区间、相邻性），不要用单个号码的冷热。cifulucky 已加入连号信号：显著时每注至少含 1 对连号。

下一步可做：按 3 套摇奖球分组检验。偏差如果是物理原因，应该集中在某一套球上，但目前还没找到每期使用哪套球的公开数据。

## 摇奖球套号与摇奖机（`scripts/ballset.py` → [`report_ballset.md`](report_ballset.md)）

`data/dlt_ballset.csv`：每期使用第几套摇奖球（福建体彩网接口的 `YaoJiangQiu` 字段，`scripts/fetch_ballset.py` 抓取），覆盖 2011 年至今共 2367 期，与开奖数据逐期核对一致。

| 问题 | 结果 |
|---|---|
| 2016 年前的偏差来自哪套球？ | 第 1、2 套显著（p=0.001、0.002），第 3 套正常。第 1、2 套的号码偏差高度相关（r=+0.58），说明有共同原因（可能是同批次的球或当时的机器） |
| 2017 年后有没有某一套球单独有偏？ | 没有。三套之间差异不显著，各套的号码偏差在前后两个时段也无法复现 |
| 小号偏移来自哪套？ | **三套都有**（z 分别为 +1.8、+1.2、+2.6），所以不是某套球的问题，更可能和**摇奖机**有关 |
| 和摇奖机更换有关吗？ | 新"维纳斯"摇奖机于 2019-09-07 启用。旧机时期（2017-01 至 2019-09）z=+0.55，新机时期 z=+3.45（p=0.0003）。偏移是逐渐出现的，没有找到明确的突变点 |
| 连号偏多来自哪套？ | **集中在第 1 套**（全部时段 z=+2.85），第 2、3 套接近理论值 |
| 能预测下一期用哪套吗？ | 不能。转移矩阵独立性 p=0.875，套号确实是随机抽取的 |

**结论**：套号无法提前预测，所以只和某一套有关的偏差（比如第 1 套的连号偏多）没法单独利用，只能按平均效果计入。小号偏移在三套球上都有，而且是在新摇奖机启用后出现的，所以它是目前最有物理依据的信号。cifulucky 现在改为只用新摇奖机启用后的数据来估计小号权重。

## 气动力学建模（`scripts/aero_sim.py` → [`report_aero.md`](report_aero.md)）

公开参数：球重 4 g、直径 45 mm、实心泡沫材质；维纳斯摇奖机靠吹气搅拌。球的终端速度约 9.4 m/s，也就是说，气流必须超过这个速度才能把球托起来。

**仿真结论**（简化物理模型：重力 + 二次阻力 + 湍流 + 碰壁 + 顶部出球管，忽略球与球的碰撞）：

1. 越轻、越大的球越容易被抽中。直径的影响是质量的 2–3 倍。
2. 敏感度取决于风速离托起临界点有多近。风速只比临界值高 10% 时，球重差 1% 会让被抽中的机会差约 2.6%；风速是临界值 3.5 倍时只差约 0.4%。
3. 反推：要造成观测到的小号偏移（1–12 号与其余号码的出现率差约 12%），1–12 号球需要轻 4–23%，或者直径大 2–9%，具体取决于风速。在接近临界的工况下，只需要轻 4.3%（0.17 g）或大 2.1%（0.9 mm），落在民间所传的 ≤5% 公差之内。
4. 2022-08-27 那次异常（气流没能托起球，只摇出 4 个号）说明机器可能确实工作在临界点附近。

**数据检验**：小号偏多呈台阶形，01–11 号整体高约 7%，并不像是搅拌不够留下的码放顺序。如果它真的来自物理原因，最可能的是这几颗球在质量或尺寸上有系统性差异。这需要实物测量才能确认，已经超出公开数据的范围。

## 深化：出球模型 + 完整开奖仿真（[`report_pl.md`](report_pl.md)、[`report_drawsim.md`](report_drawsim.md)）

**A. 统计：用出球顺序反推每颗球的有效权重**（Plackett-Luce 模型，`scripts/pl_model.py`）
- 新机时期，只有"01–11 台阶"这一个模型在样本外跑赢随机：5 个时间块全部为正，合计 +9.1 比特。按每个号码单独估权重、按每套球单独估权重的模型都跑不赢随机，说明单颗球没有独特的"指纹"。
- 严格版（分界点也只用训练数据来选）：+4.0 比特，3/5 块为正；有 3 折从训练数据里独立选出了"01–11"作为分界。
- 01–11 号的有效权重是其余号码的 **×1.112**（95% CI 1.044–1.180）。旧机时期方向相反（×0.951，偏大号）。

**B. 物理：完整开奖仿真**（`scripts/draw_sim.py`，numba 加速）
- 35 颗球、球与球碰撞、先搅拌再逐个出球。每次开奖内每颗球的质量和直径在公差范围内随机。对 7 个不确定参数做拉丁超立方采样，共 24 组，每组 6144 次开奖，总计约 15 万次。
- 质量弹性 −0.3 到 −1.5，直径弹性 +0.5 到 +3.1：**直径的影响约是质量的 2–3 倍**，风速越接近托起临界点越敏感。
- 把 A 的结果和 B 的敏感度对接（合成两边的不确定性）：要解释 ×1.112 的权重差，01–11 号球需要轻 7–27%（中位数 13%，约 0.54 g），或直径大 3–10%（中位数 5.4%，约 2.4 mm）。若机器工作在临界附近，只需轻 7–9% 或大 3.5–4.6%。
- 仿真中搅拌后的"码放顺序记忆"只有 ×1.00±0.02，**这个解释被排除**。

**结论**：物理上要成立，需要机器工作在临界点附近，并且三套球的 01–11 号都在公差边缘、朝同一方向偏。统计上，严格验证下信号偏弱（3/5 块为正）。两种解释都还不能排除，接下来几十期的新数据是最好的裁判。

## cifulucky 当前策略（基于全部研究）

```bash
python3 cifulucky.py --update   # 抓开奖 + 出球顺序/套号 → 重新拟合信号 → 生成 5 注
```

- **台阶信号**：每次运行都用新摇奖机启用以来的出球顺序重新拟合"01–11 号权重"（Plackett-Luce 模型 + 似然比检验）。显著时，**前区 5 个号全部从 01–11 中选**：
  - 如果开奖真随机，每种组合概率相同，这样选**没有任何损失**；
  - 如果信号真实，这是概率最高的区域。权重向 1 收缩一半后，每注头奖概率约 ×1.2；按原始估计约 ×1.5。
- **连号信号**：显著时每注至少含 1 对连号。
- 信号消失（z ≤ 2）时自动退回 35 选 5 均匀随机。
- 后区没有可靠信号，随机选。

## 全历史组合深度分析（`scripts/combo_deep.py` → [`report_combo.md`](report_combo.md)）

| 检验 | 结果 |
|---|---|
| 前区完全重复 | 18 次（随机期望 13.2，正常） |
| 头奖号码（前区+后区）完整重现 | **2 次**（期望 0.2，p≈0.018）。重现那期头奖分别有 21 注和 35 注，说明**很多人专门买历史头奖号码** |
| 每期与历史最近邻的重合数、4 码和 3 码子组合重复 | 都在随机范围内 |
| 联合形态（三区比 × 奇偶 × 连号） | 2016 年前偏离（p=0.003），2017 年后正常（p=0.47） |
| 组合打分法的样本外排名（逐期只用过去数据打分） | 号码对共现、三码共现、近期相似度、形态频率、上期重号：2017 年后全部无效。只有"01–11 个数"在新机时期有效（排名 0.523，p=0.010） |
| 组合空间地图 | 每一种组合都至少和某期历史开奖重 3 个号，73% 能重 4 个号 |

**结论**：组合层面的结构，最终也只剩"01–11"这一条信号，其余组合选号法（共现、杀号、形态、相似度）都没有样本外预测力。cifulucky 的策略不用改。另外，要避开历史头奖号码：中奖概率和别的组合一样，但中了要和很多人平分。

## 只看 2018 年起：发现期 → 验证期（`scripts/recent_deep.py` → [`report_recent.md`](report_recent.md)）

- 发现期（2018–2023，888 期）扫描了 1476 个假设：号段、单号、余数、尾数、分套号段、出球位置、后区、形态。**没有一个通过多重检验校正。**
- 发现期前 10 名拿到验证期（2024 至今，416 期）检验，**没有一个通过 Bonferroni 校正**；7/10 同向，同向的几乎都和"小号偏多"有关。
- 01–11 的权重：发现期 ×1.085、验证期 ×1.123（z=+2.48），两段一致；2018 年至今合计 ×1.097（z=+3.51）。
- **新摇奖机启用后最初 47 期，01–11 权重高达 ×1.54**（z=+3.2），之后回落并稳定在 ×1.05–1.12，可能和新机磨合有关。
- 后区没有任何可复现的信号。

结论：近 8 年的数据里，"小号偏多"是唯一反复出现的现象。它不是单独一个很强的信号，而是一族方向一致的弱信号。真实强度更可能在 ×1.05–1.10 之间，cifulucky 收缩后用的 ×1.055 与此吻合。
