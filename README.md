# 大乐透研究：能不能做最幸运的那一个？

数据：2007-05 ~ 2026-10 全部 **2932 期**开奖（`data/dlt_history.csv`，来源 500.com）。
复现：`python3 scripts/fetch.py && python3 scripts/analyze.py`，完整输出见 `analysis.txt`。

## 结论（一句话）

**现在的大乐透开奖是真随机的，没有任何选号方法能提高中奖概率；唯一能做的是：中了的时候少跟人分钱。**

## 关键发现

| # | 问题 | 结果 |
|---|------|------|
| 1 | 头奖有多难？ | 1 / 21,425,712。每周 3 期各买 1 注，平均约 **13.7 万年**中一次 |
| 2 | 号码均匀吗？ | **2007–2016 不均匀**：29–35 号明显偏多（χ²=166 / 61，远超临界值 48.6），疑似早期摇奖球/设备偏差。**2017 年后完全均匀**（χ²≈26，正好是随机水平） |
| 3 | 冷热号有用吗？ | 全时段回测"追热号"前区命中 0.775（期望 0.714，+4σ）——但这全是 2016 年前的设备偏差带来的。**2017 年后热号 0.727、冷号 0.723、随机 0.734，没有区别** |
| 4 | 选号影响奖金吗？ | 会。有 ≥2 对连号的开奖，一等奖注数中位数高约 30%（1.72 vs 1.33 注/亿元销量），即更多人买、奖金被分薄。历史最多一期 106 注同中（16150） |
| 5 | 奖金实际多少？ | 近 3 年一等奖单注中位数 1000 万（封顶），最低一期仅 239 万（26113 期：02 04 06 10 11，37 注平分） |

## 如果一定要买

1. **随机机选**，别迷信冷热号、走势图、"缩水"软件——2017 年后它们都等于随机。
2. **避开热门组合**：连号、等差数列、全在 1–31（生日）的号、上期号码。不提高中奖率，但中了少被分。
3. 期望回报约每 2 元回 1 元（法定返奖率约 50%），**当娱乐消费，不当投资**。

## 有意思的副产品

2007–2016 年的偏差是真实且可被利用的（前区追热号显著优于随机），说明早期设备确实有问题，后来被修正了。这也是全部研究里唯一"不随机"的信号。
